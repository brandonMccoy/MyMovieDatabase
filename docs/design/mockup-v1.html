The keyboard button on the camera screen opens manual entry with the same review form. Format is auto-detected from the barcode database's product name ("…[4K UHD]") but can be changed with one tap. Fields you edit get an amber outline so you can see what you changed from the online data. Scanning a film you already own on another format adds that format to the existing film instead of creating a duplicate. Wishlist alert: as soon as a scan matches something on your wishlist, an amber banner appears over the camera (left), and the review screen repeats it (right). Saving takes the item off the wishlist.
