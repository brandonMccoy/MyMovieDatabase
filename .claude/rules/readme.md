# README rules

Check these as part of every change, before it is committed.

- **Screenshots follow the UI.** If a change alters how a screen looks, and that screen is shown in a README screenshot (`docs/screenshots/`, and the phone scan shot in `docs/design/m5-preview/`), retake the screenshot in the same change. A newly created screen can get a screenshot of its own, added to the existing Screenshots section.
- **Existing sections stay true.** If a change affects something an existing README section describes, update that section in the same change.
- **No new sections.** Don't add a section (a heading of any level) to the README unless the user explicitly says to. If a change seems to need one, say so and ask.
